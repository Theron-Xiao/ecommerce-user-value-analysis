# 电商用户消费行为与价值分析报告

## 1. 业务背景

电商平台希望识别高价值用户、理解不同人群的消费差异，并寻找可运营的商品组合，为精细化运营与会员策略提供数据依据。

## 2. 数据说明

使用 Kaggle Black Friday 数据集，约 78 万条交易记录，字段覆盖用户属性、商品类别与购买金额。数据为单次促销快照，无时间戳与行为链路。

## 3. 数据处理

- 次要类别 `Product_Category_2/3` 缺失比例高，作为次要维度不做填充处理。
- 去除重复用户记录，按 `User_ID` 聚合总购买量。
- 对 `Gender`、`Age`、`City_Category`、`Stay_In_Current_City_Years` 重新编码分类。

## 4. 探索性发现

- 男性购买数据多于女性。
- 36–45 岁用户最多，26–35 与 46–50 人数接近。
- 职业 1、4、6 购物较多，其中职业 1 最多。
- 城市 C 购买量较大；多数用户在当前城市居住 1–2 年。
- 未婚与已婚整体购买差异不明显，未婚略多。
- 各字段间相关性整体不强。

## 5. 高价值用户识别

以「消费频次 + 消费金额」双高作为高价值用户定义，使用逻辑回归与决策树构建分类模型并评估。训练集口径下逻辑回归表现较好（精确率约 95.5%、召回率约 97.3%），但需注意训练 / 测试划分口径，结论仅作探索参考。

## 6. 关联规则分析

对 20 种主商品类别使用 Apriori 算法，未挖掘出强关联规则。观察显示商品与用户基本为点对点购买，数据独立性较强，直接做捆绑推荐价值有限。

## 7. 业务建议

- 以 36–45 岁、城市 C、高频高额群体为核心做会员分层。
- 高价值用户侧重复购激励，中等价值用户侧重频次提升。
- 补充浏览、加购、留存等行为数据后，再做转化漏斗与留存分析。
